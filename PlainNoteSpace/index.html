Plain NoteSpace

Windows용 심플한 노트 작업 공간

앱 소개

Plain NoteSpace는 글쓰기, 정리, 일별 기록을 한곳에서 관리할 수 있는 Windows용 노트 앱입니다. 서식 있는 노트 작성, 여러 노트 탭 관리, 날짜별 메모, 시각적인 파일 정리, OneDrive 동기화 기능을 통해 나만의 노트 공간을 가볍고 편하게 만들 수 있습니다.

주요 기능

  • 서식 있는 노트 작성: 글꼴, 크기, 굵게, 기울임, 밑줄, 강조 등 기본 서식 지원
  • 탭 기반 편집: 여러 노트를 동시에 열고 빠르게 전환하며 작업
  • 자동 저장: 작업 중인 노트를 일정 간격으로 자동 저장
  • 일별 메모: 캘린더에서 날짜를 선택해 하루 기록을 작성하고 관리
  • 파일 공간 보기: 노트와 폴더를 시각적인 카드 형태로 확인하고 정리
  • 노트 검색 및 최근 파일: 자주 사용하는 노트에 빠르게 접근
  • 내보내기: 작성한 노트를 TXT 또는 HTML 형식으로 내보내기
  • OneDrive 동기화: Microsoft 계정으로 로그인하여 노트 파일을 OneDrive에 동기화
  • 테마: 라이트 / 다크 / 시스템 설정 자동 적용
  • 배경 효과: Mica / Acrylic 효과 지원
  • 다국어: 한국어 · 영어 · 일본어 · 중국어 간체 지원
🔒 개인정보 안내: 기본적으로 노트 파일은 사용자의 기기에 저장됩니다. OneDrive 동기화 기능을 사용하는 경우에만 사용자가 로그인한 Microsoft 계정의 OneDrive로 노트 파일이 업로드됩니다. 앱은 광고나 분석 목적으로 노트 내용을 수집하지 않습니다.
💡 이런 분께 추천합니다: 복잡한 협업 도구보다 가볍게 실행되는 개인 노트 앱을 원하거나, 수업 준비, 업무 메모, 하루 기록, 아이디어 정리를 한곳에서 관리하고 싶은 사용자에게 적합합니다.

시스템 요구사항

  • Windows 10 버전 1903 이상 / Windows 11 권장
  • .NET 8.0 Runtime
  • x86 / x64 / ARM64
  • OneDrive 동기화 사용 시 Microsoft 계정 필요

Plain NoteSpace

A simple note workspace for Windows

About the App

Plain NoteSpace is a simple note-taking app for Windows that helps you write, organize, and manage daily notes in one place. With rich text editing, multiple note tabs, calendar-based daily notes, visual file organization, and optional OneDrive sync, you can create your own lightweight note workspace.

Main Features

  • Rich text editing: Supports basic formatting such as font, size, bold, italic, underline, and highlighting
  • Tabbed editing: Open multiple notes and switch between them easily
  • Auto save: Automatically saves your work at regular intervals
  • Daily notes: Select a date from the calendar and manage notes by day
  • Visual file space: View and organize notes and folders as visual cards
  • Search and recent files: Quickly access frequently used notes
  • Export: Export your notes as TXT or HTML files
  • OneDrive sync: Sign in with your Microsoft account to sync note files to OneDrive
  • Themes: Supports light, dark, and system theme modes
  • Backdrop effects: Supports Mica and Acrylic effects
  • Multilingual support: Korean, English, Japanese, and Simplified Chinese
🔒 Privacy Notice: By default, your note files are stored on your device. If you choose to use OneDrive sync, your note files are uploaded only to the OneDrive account you sign in with. The app does not collect note contents for advertising or analytics purposes.
💡 Recommended for: Users who want a lightweight personal note app rather than a complex collaboration tool. It is useful for class preparation, work notes, daily journaling, and organizing ideas.

System Requirements

  • Windows 10 version 1903 or later / Windows 11 recommended
  • .NET 8.0 Runtime
  • x86 / x64 / ARM64
  • Microsoft account required for OneDrive sync
