개인정보 처리방침

Plain NoteSpace

최종 업데이트: 2026년 7월
요약: Plain NoteSpace는 기본적으로 사용자의 노트 파일과 설정을 사용자의 기기에 저장합니다. OneDrive 동기화 기능을 사용하는 경우에만, 사용자가 로그인한 Microsoft 계정의 OneDrive로 노트 파일이 업로드됩니다. 앱은 광고나 분석 목적으로 사용자의 노트 내용을 수집하지 않습니다.

1. 수집 또는 저장하는 정보

Plain NoteSpace는 앱 기능 제공을 위해 다음 정보를 사용자의 기기 또는 사용자가 선택한 OneDrive에 저장할 수 있습니다:

  • 노트 파일: 사용자가 작성한 RTF, TXT 형식의 노트 파일
  • 일별 메모: 캘린더 날짜별로 작성한 노트 파일
  • 파일 및 폴더 배치 정보: 노트 공간 보기에서 사용자가 정리한 카드 위치, 확대/축소 상태 등
  • 앱 설정: 언어, 테마, 배경 효과, 기본 글꼴 크기, 자동 저장 간격 등 사용자 환경설정
  • 최근 파일 정보: 사용자가 최근에 열었던 노트 파일 경로
  • Microsoft 계정 정보: OneDrive 동기화를 사용하는 경우, 로그인 상태 표시 및 동기화 기능 제공을 위해 Microsoft 계정의 기본 프로필 정보가 사용될 수 있습니다

2. 정보 사용 목적

위 정보는 다음 목적을 위해서만 사용됩니다:

  • 노트 작성, 편집, 저장 및 불러오기
  • 날짜별 메모 관리
  • 노트와 폴더의 시각적 정리 상태 복원
  • 사용자 설정 유지
  • OneDrive 동기화 기능 제공
  • 최근 파일 목록 표시

Plain NoteSpace는 사용자의 노트 내용을 광고, 분석, 마케팅 목적으로 사용하지 않습니다.

3. 데이터 저장 위치

Plain NoteSpace의 데이터는 다음 위치에 저장될 수 있습니다:

  • 로컬 노트 파일: 사용자의 문서 폴더 또는 사용자가 선택한 저장 위치
  • 앱 설정 및 인증 캐시: Windows의 로컬 앱 데이터 폴더
  • OneDrive 동기화 파일: 사용자가 OneDrive 동기화를 활성화한 경우, 사용자의 Microsoft OneDrive 저장소

사용자는 로컬 파일을 직접 삭제하거나, OneDrive에 업로드된 파일을 자신의 OneDrive에서 직접 관리할 수 있습니다.

4. OneDrive 동기화

Plain NoteSpace는 선택 기능으로 OneDrive 동기화를 제공할 수 있습니다. 이 기능을 사용하려면 Microsoft 계정 로그인이 필요하며, 앱은 노트 파일을 사용자의 OneDrive에 업로드하거나 OneDrive에서 다운로드하기 위해 필요한 권한을 요청할 수 있습니다.

  • OneDrive 동기화는 사용자가 직접 로그인하고 기능을 사용하는 경우에만 작동합니다
  • 동기화된 파일은 개발자 서버가 아닌 사용자의 Microsoft OneDrive 계정에 저장됩니다
  • 개발자는 사용자의 OneDrive 파일 내용에 별도로 접근하거나 저장하지 않습니다
  • 사용자는 앱에서 로그아웃하거나 Microsoft 계정 권한을 해제하여 동기화 사용을 중단할 수 있습니다

5. 수집하지 않는 정보

Plain NoteSpace는 다음 정보를 광고나 분석 목적으로 수집하지 않습니다:

  • 노트 내용의 원격 수집
  • 사용 통계 또는 행동 분석 데이터
  • 광고 식별자 또는 추적 데이터
  • 위치 정보
  • 연락처, 사진, 마이크, 카메라 등 노트 기능과 무관한 정보

6. 제3자 공유

Plain NoteSpace는 사용자의 노트 내용이나 앱 데이터를 광고 회사, 분석 업체 등 제3자에게 판매하거나 공유하지 않습니다. 단, 사용자가 OneDrive 동기화를 사용하는 경우 파일 저장과 동기화는 Microsoft의 OneDrive 및 Microsoft 계정 서비스를 통해 이루어집니다.

7. 데이터 보안

로컬 데이터는 사용자의 기기에 저장되며 Windows 계정 보호, 파일 시스템 권한 등 기기 수준의 보안에 따릅니다. OneDrive 동기화 데이터는 Microsoft 계정 및 OneDrive의 보안 체계에 따라 보호됩니다. 사용자는 중요한 노트 파일을 관리할 때 자신의 Windows 계정과 Microsoft 계정 보안을 유지해야 합니다.

8. 사용자의 선택과 제어

사용자는 다음과 같은 방법으로 자신의 데이터를 관리할 수 있습니다:

  • 노트 파일을 직접 삭제하거나 이동
  • 앱 설정 변경 또는 초기화
  • OneDrive에서 동기화된 노트 파일 삭제
  • 앱에서 Microsoft 계정 로그아웃
  • Microsoft 계정 관리 페이지에서 앱 권한 해제
  • 앱 제거를 통해 로컬 앱 데이터 삭제

9. 아동 개인정보 보호

Plain NoteSpace는 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

10. 방침 변경

본 개인정보 처리방침은 필요 시 업데이트될 수 있습니다. 중요한 변경 사항이 있을 경우 앱 스토어 업데이트 노트 또는 이 페이지를 통해 안내합니다. 최신 방침은 항상 이 페이지에서 확인하실 수 있습니다.

Privacy Policy

Plain NoteSpace

Last updated: July 2026
Summary: Plain NoteSpace stores your note files and settings on your device by default. If you choose to use OneDrive sync, your note files are uploaded only to the Microsoft OneDrive account you sign in with. The app does not collect your note contents for advertising or analytics purposes.

1. Information We Store or Use

Plain NoteSpace may store or use the following information to provide its features:

  • Note files: RTF and TXT note files created by the user
  • Daily notes: Notes created for specific calendar dates
  • File and folder layout data: Card positions, zoom level, and layout information in the visual file space
  • App settings: Language, theme, backdrop effect, default font size, auto-save interval, and other preferences
  • Recent file information: Paths of recently opened note files
  • Microsoft account information: If you use OneDrive sync, basic Microsoft account profile information may be used to show sign-in status and provide sync features

2. How We Use Information

The information above is used only for the following purposes:

  • Creating, editing, saving, and opening notes
  • Managing daily notes by calendar date
  • Restoring the visual organization of notes and folders
  • Keeping user preferences
  • Providing OneDrive sync
  • Displaying recent files

Plain NoteSpace does not use your note contents for advertising, analytics, or marketing purposes.

3. Data Storage Location

Plain NoteSpace data may be stored in the following locations:

  • Local note files: Your Documents folder or another location you choose
  • App settings and authentication cache: The local app data folder on Windows
  • OneDrive synced files: Your Microsoft OneDrive storage, if you enable OneDrive sync

You can delete local files directly or manage synced files from your own OneDrive account.

4. OneDrive Sync

Plain NoteSpace may provide OneDrive sync as an optional feature. To use this feature, you need to sign in with a Microsoft account. The app may request the permissions necessary to upload note files to your OneDrive or download note files from your OneDrive.

  • OneDrive sync works only when you sign in and choose to use the feature
  • Synced files are stored in your Microsoft OneDrive account, not on the developer’s server
  • The developer does not separately access or store the contents of your OneDrive files
  • You can stop using sync by signing out of the app or revoking the app’s Microsoft account permissions

5. Information We Do Not Collect

Plain NoteSpace does not collect the following information for advertising or analytics purposes:

  • Remote collection of note contents
  • Usage statistics or behavioral analytics data
  • Advertising identifiers or tracking data
  • Location information
  • Contacts, photos, microphone, camera, or other information unrelated to note-taking features

6. Third-Party Sharing

Plain NoteSpace does not sell or share your note contents or app data with advertisers, analytics providers, or other third parties. However, if you use OneDrive sync, file storage and synchronization are provided through Microsoft OneDrive and Microsoft account services.

7. Data Security

Local data is stored on your device and is protected according to your Windows account, file system permissions, and device-level security. OneDrive synced data is protected according to Microsoft account and OneDrive security. You are responsible for keeping your Windows account and Microsoft account secure when managing important note files.

8. Your Choices and Controls

You can manage your data in the following ways:

  • Delete or move note files directly
  • Change or reset app settings
  • Delete synced note files from OneDrive
  • Sign out of your Microsoft account in the app
  • Revoke app permissions from your Microsoft account management page
  • Uninstall the app to remove local app data

9. Children’s Privacy

Plain NoteSpace is not directed to children under the age of 13 and does not knowingly collect personal information from children.

10. Changes to This Policy

This Privacy Policy may be updated when necessary. Important changes may be announced through app store update notes or on this page. The latest version of the policy will always be available on this page.
