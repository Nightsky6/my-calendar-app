📋 Plain Clipboard

Windows용 스마트 클립보드 히스토리 관리 앱

앱 소개

Plain Clipboard는 Windows에서 복사한 모든 텍스트와 이미지를 자동으로 기록하고, 즐겨찾기 저장, 빠른 검색, 이모지 입력, 다크 모드 등 다양한 기능을 제공하는 가볍고 빠른 클립보드 관리 앱입니다.

주요 기능

  • 클립보드 히스토리: 복사한 텍스트·이미지를 자동으로 기록하고 즉시 재사용
  • 즐겨찾기: 자주 사용하는 문구를 #태그와 함께 저장하고 빠르게 검색
  • 이모지 피커: 내장 이모지 목록에서 한 번 클릭으로 복사
  • 테마: 라이트 / 다크 / 시스템 설정 자동 적용
  • 배경 효과: Mica / Acrylic 유리 효과 지원
  • 시스템 트레이: 트레이 아이콘으로 항상 빠르게 접근
  • 항상 위: 다른 창 위에 고정하여 사용 가능
  • 다국어: 한국어 · 영어 · 일본어 지원
  • 데이터 내보내기/가져오기: 즐겨찾기 백업 및 복원
🔒 개인정보 우선: 모든 클립보드 데이터는 사용자의 기기에만 저장됩니다. 외부 서버로 전송되거나 광고, 분석에 활용되지 않습니다.

시스템 요구사항

  • Windows 10 (버전 1903) 이상 / Windows 11 권장
  • .NET 8.0 Runtime
  • x86 / x64 / ARM64
