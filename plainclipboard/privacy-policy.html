개인정보 처리방침

Plain Clipboard

최종 업데이트: 2025년 1월
요약: Plain Clipboard는 사용자의 데이터를 외부 서버로 전송하지 않습니다. 모든 클립보드 데이터는 사용자의 기기에만 저장되며, 광고나 분석 목적으로 활용되지 않습니다.

1. 수집하는 정보

Plain Clipboard는 다음 데이터를 사용자의 기기 내 로컬 저장소에만 저장합니다:

  • 클립보드 히스토리: 사용자가 복사한 텍스트 및 이미지
  • 즐겨찾기: 사용자가 직접 저장한 문구 및 태그
  • 앱 설정: 테마, 배경 효과, 언어, 트레이 동작 등 사용자 환경설정

위 데이터는 오직 앱 기능 제공을 위해서만 사용되며, 외부 서버나 제3자에게 전송되지 않습니다.

2. 수집하지 않는 정보

Plain Clipboard는 다음 정보를 수집하지 않습니다:

  • 사용자 이름, 이메일 주소 등 개인 식별 정보
  • 사용 통계, 분석 데이터 (Analytics)
  • 광고 식별자 또는 추적 데이터
  • 네트워크 요청 또는 원격 서버 통신

3. 데이터 저장 위치

모든 데이터는 사용자 기기의 로컬 앱 데이터 폴더에 저장됩니다:

  • 경로: %LOCALAPPDATA%\PlainClipboard\
  • 클립보드 히스토리, 즐겨찾기, 설정 파일이 이 위치에 JSON 형식으로 저장됩니다
  • 사용자는 언제든지 이 폴더의 파일을 삭제하여 모든 데이터를 제거할 수 있습니다

4. 제3자 공유

Plain Clipboard는 사용자 데이터를 어떠한 제3자와도 공유하지 않습니다. 광고 네트워크, 분석 서비스, 클라우드 서버에 데이터를 전송하는 기능이 없습니다.

5. 데이터 보안

모든 데이터는 사용자의 기기에만 존재하므로, 기기 수준의 보안(Windows 계정 보호, 파일 시스템 권한 등)이 적용됩니다. 앱 자체에서 별도의 암호화를 수행하지는 않으나, 외부 접근 경로가 존재하지 않습니다.

6. 아동 개인정보 보호

Plain Clipboard는 13세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 방침 변경

본 개인정보 처리방침은 필요 시 업데이트될 수 있습니다. 중요한 변경 사항이 있을 경우 앱 스토어 업데이트 노트를 통해 안내합니다. 최신 방침은 항상 이 페이지에서 확인하실 수 있습니다.
