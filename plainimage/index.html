Plain Image Viewer

빠르고 가볍게, 모든 이미지를 — Windows 네이티브 이미지 뷰어 Fast, Lightweight, Every Image — Windows Native Image Viewer

애플리케이션 소개 About

Plain Image Viewer는 Windows 환경에서 동작하는 빠르고 가벼운 네이티브 이미지 뷰어입니다. JPEG, PNG, BMP, GIF, TIFF, WebP, SVG, RAW 등 다양한 이미지 형식을 지원하며, 복잡한 설치 없이 즉시 사용할 수 있습니다. Plain Image Viewer is a fast and lightweight native Windows image viewer. It supports a wide range of formats including JPEG, PNG, BMP, GIF, TIFF, WebP, SVG, and RAW, and is ready to use instantly without complex setup.

Plain Image Viewer를 선택하는 이유 Why Plain Image Viewer?

  • 빠른 실행 속도: 가볍고 빠른 네이티브 Win32 기반으로 즉시 이미지를 열 수 있습니다 Fast Launch: Opens images instantly with a lightweight native Win32 engine
  • 다양한 형식 지원: JPG, PNG, BMP, GIF, TIFF, WebP, ICO, SVG, 다양한 RAW 포맷 지원 Wide Format Support: JPG, PNG, BMP, GIF, TIFF, WebP, ICO, SVG, and major RAW formats
  • 깔끔한 UI: Windows 11 디자인에 어울리는 Fluent 스타일 인터페이스 Clean UI: Fluent-style interface designed for Windows 11
  • 개인정보 보호: 인터넷 연결 없이 모든 기능을 로컬에서 처리 Privacy-First: All features work locally without any internet connection

주요 기능 Key Features

  • 이미지 탐색: 폴더 내 이미지를 키보드 또는 썸네일 바로 빠르게 탐색 Image Navigation: Browse images in a folder via keyboard or thumbnail strip
  • 썸네일 필름스트립: 하단 썸네일 바로 폴더 내 이미지를 한눈에 확인 Thumbnail Filmstrip: Preview all images in a folder at a glance from the bottom bar
  • 확대/축소 및 이동: 마우스 휠 확대/축소, 드래그 이동 지원 Zoom & Pan: Mouse wheel zoom and drag-to-pan support
  • 이미지 회전 및 반전: 좌/우 회전 및 좌우/상하 반전 Rotate & Flip: Rotate left/right and flip horizontally/vertically
  • 이미지 보정: 밝기, 대비, 채도, 선명도 등 기본 보정 기능 Image Adjustments: Brightness, contrast, saturation, and sharpness controls
  • 슬라이드쇼: 자동 슬라이드쇼 재생 지원 Slideshow: Auto-play slideshow support
  • EXIF 정보 보기: 촬영 날짜, 카메라 모델, GPS 등 메타데이터 확인 EXIF Viewer: View metadata including date taken, camera model, and GPS info
  • 파일 연결 설정: 원하는 이미지 형식을 기본 앱으로 등록 File Association: Set Plain Image Viewer as the default app for your preferred formats
  • 배경화면 설정: 현재 이미지를 Windows 배경화면으로 즉시 적용 Set as Wallpaper: Apply the current image as your Windows desktop wallpaper instantly

지원 이미지 형식 Supported Formats

  • 일반 형식: JPEG, PNG, BMP, GIF, TIFF, WebP, ICO Standard: JPEG, PNG, BMP, GIF, TIFF, WebP, ICO
  • 벡터: SVG Vector: SVG
  • RAW 형식: CR2, CR3, NEF, ARW, DNG, ORF, RW2 등 주요 카메라 RAW 포맷 RAW: CR2, CR3, NEF, ARW, DNG, ORF, RW2, and more

단축키 Keyboard Shortcuts

  • ← / →: 이전 / 다음 이미지 ← / →: Previous / Next image
  • Ctrl + O: 파일 열기 Ctrl + O: Open file
  • Ctrl + E: EXIF 정보 보기 Ctrl + E: View EXIF info
  • Ctrl + S: 이미지 저장 Ctrl + S: Save image
  • F5: 슬라이드쇼 시작/중지 F5: Start / Stop slideshow
  • F11: 전체 화면 F11: Toggle fullscreen
  • + / −: 확대 / 축소 + / −: Zoom in / Zoom out
  • 0: 원본 크기로 초기화 0: Reset to original size
개인정보: Plain Image Viewer는 인터넷에 연결하지 않으며, 사용자의 이미지 및 데이터를 외부로 전송하지 않습니다. 모든 처리는 사용자 기기 내에서만 이루어집니다. Privacy: Plain Image Viewer does not connect to the internet and never transmits your images or data externally. All processing happens entirely on your device.
