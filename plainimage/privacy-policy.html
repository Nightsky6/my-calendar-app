Privacy Policy

Last Updated: May 15, 2026

Plain Image Viewer does not collect, transmit, or store any personal information. All operations are performed entirely on your local device.

1. Introduction

This Privacy Policy describes how Plain Image Viewer ("we", "our", or "the Application") handles your information. Plain Image Viewer is a local Windows desktop application for viewing images and does not connect to any external servers or services.

2. Information We Collect

We collect NO personal information whatsoever.
  • No account or login required
  • No analytics or usage statistics collected
  • No device information transmitted
  • No cookies or tracking technologies used
  • No network connections made

3. How the Application Works

Plain Image Viewer operates entirely offline and locally:

  • Image Display: Opens and displays image files stored on your device
  • File Association: Optionally registers as the default viewer for image file types — stored in Windows Registry on your local device only
  • Recent Files: A list of recently opened files is stored locally in the Windows Registry for convenience
  • Print: Sends image data directly to your local printer — no external service involved

4. Local Data Storage

The only data stored by Plain Image Viewer is:

  • Recent file list: Paths of recently opened files, stored in Windows Registry (HKCU\Software\PlainImageViewer)
  • File associations: Default application settings, stored in Windows Registry

This data never leaves your device and can be removed by uninstalling the application.

5. Data Sharing and Third Parties

Plain Image Viewer does not share any data with third parties. The application does not communicate with any external servers or services.

6. Supported File Formats

The application reads image files from your local storage for display purposes only. No image data is uploaded, transmitted, or stored externally. Supported formats include common image types (JPEG, PNG, BMP, GIF, TIFF, WebP, SVG) and RAW camera formats via LibRaw.

7. Children's Privacy

Plain Image Viewer does not collect any information from any users, including children. The application is safe for use by all ages.

8. Your Rights and Choices

  • Recent Files: Can be cleared from within the application at any time
  • File Associations: Can be changed or removed from within the application or Windows Settings
  • Full Removal: Uninstalling the application removes all associated registry entries

We may update this Privacy Policy from time to time. Changes will be posted on this page with an updated "Last Updated" date.
