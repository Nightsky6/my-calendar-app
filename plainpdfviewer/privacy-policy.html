개인정보처리방침

최종 업데이트: 2026년 5월 15일

Plain PDF Viewer는 어떠한 개인정보도 수집, 전송, 저장하지 않습니다. 모든 작업은 사용자의 로컬 기기에서만 수행됩니다.

1. 소개

본 개인정보처리방침은 Plain PDF Viewer(이하 "본 애플리케이션")가 사용자의 정보를 어떻게 처리하는지 설명합니다. Plain PDF Viewer는 PDF 문서를 열람하기 위한 Windows 로컬 데스크톱 애플리케이션으로, 어떠한 외부 서버나 서비스에도 연결하지 않습니다.

2. 수집하는 정보

본 애플리케이션은 개인정보를 일절 수집하지 않습니다.
  • 계정 또는 로그인 불필요
  • 분석 데이터 또는 사용 통계 수집 없음
  • 기기 정보 전송 없음
  • 쿠키 또는 추적 기술 미사용
  • 네트워크 연결 없음

3. 애플리케이션 동작 방식

Plain PDF Viewer는 완전히 오프라인 로컬 환경에서 동작합니다:

  • PDF 열람: 기기에 저장된 PDF 파일을 열어 표시합니다.
  • 페이지 탐색 및 검색: 모든 처리는 로컬에서만 수행되며 외부로 전송되지 않습니다.
  • 바로가기(QuickJump): 사용자가 등록한 검색어 바로가기 목록은 로컬 Windows 레지스트리에만 저장됩니다.
  • 환경설정: 화면 모드, 줌, 다크모드 등 설정값은 로컬 레지스트리에만 저장됩니다.
  • 인쇄: 이미지 데이터를 로컬 프린터로 직접 전송하며 외부 서비스가 개입하지 않습니다.

4. 로컬 데이터 저장

Plain PDF Viewer가 저장하는 유일한 데이터는 다음과 같습니다:

  • 환경설정: 다크모드, 줌 수준, 레이아웃 등 앱 설정값 — Windows 레지스트리 (HKCU\Software\PlainPDFViewer)에 저장
  • 바로가기 목록: 사용자가 직접 등록한 검색어 및 이름 — Windows 레지스트리 (HKCU\Software\PlainPDFViewer\QuickJumps)에 저장

이 데이터는 기기 밖으로 전송되지 않으며, 애플리케이션을 제거하면 함께 삭제됩니다.

5. 제3자 데이터 공유

Plain PDF Viewer는 어떠한 데이터도 제3자와 공유하지 않습니다. 본 애플리케이션은 외부 서버나 서비스와 통신하지 않습니다.

6. 지원 파일 형식

본 애플리케이션은 로컬 저장소의 PDF 파일을 열람 목적으로만 읽습니다. PDF 데이터는 업로드, 전송 또는 외부에 저장되지 않습니다. PDFium 라이브러리를 사용하여 렌더링하며, 모든 처리는 로컬에서 완료됩니다.

7. 아동 개인정보 보호

Plain PDF Viewer는 연령에 관계없이 어떠한 사용자의 정보도 수집하지 않습니다. 본 애플리케이션은 모든 연령대가 안전하게 사용할 수 있습니다.

8. 사용자 권리 및 선택

  • 바로가기 목록: 애플리케이션 내에서 언제든지 항목을 삭제할 수 있습니다.
  • 환경설정 초기화: 레지스트리 항목을 수동으로 삭제하거나 앱을 제거하면 모든 설정이 제거됩니다.
  • 완전 제거: 애플리케이션을 제거하면 관련된 모든 레지스트리 항목이 함께 삭제됩니다.

9. 개인정보처리방침 변경

본 개인정보처리방침은 필요에 따라 업데이트될 수 있습니다. 변경 사항은 이 페이지에 "최종 업데이트" 날짜와 함께 게시됩니다.

Privacy Policy

Last Updated: May 15, 2026

Plain PDF Viewer does not collect, transmit, or store any personal information. All operations are performed entirely on your local device.

1. Introduction

This Privacy Policy describes how Plain PDF Viewer ("the Application") handles your information. Plain PDF Viewer is a local Windows desktop application for viewing PDF documents and does not connect to any external servers or services.

2. Information We Collect

We collect NO personal information whatsoever.
  • No account or login required
  • No analytics or usage statistics collected
  • No device information transmitted
  • No cookies or tracking technologies used
  • No network connections made

3. How the Application Works

Plain PDF Viewer operates entirely offline and locally:

  • PDF Display: Opens and displays PDF files stored on your device.
  • Page Navigation & Search: All processing is performed locally and nothing is transmitted externally.
  • QuickJump Shortcuts: User-registered keyword shortcuts are stored only in the local Windows Registry.
  • Preferences: Settings such as view mode, zoom level, and dark mode are stored only in the local Registry.
  • Print: Document data is sent directly to your local printer — no external service is involved.

4. Local Data Storage

The only data stored by Plain PDF Viewer is:

  • Preferences: App settings such as dark mode, zoom level, and layout — stored in Windows Registry (HKCU\Software\PlainPDFViewer)
  • QuickJump list: User-registered keywords and labels — stored in Windows Registry (HKCU\Software\PlainPDFViewer\QuickJumps)

This data never leaves your device and can be removed by uninstalling the application.

5. Data Sharing and Third Parties

Plain PDF Viewer does not share any data with third parties. The application does not communicate with any external servers or services.

6. Supported File Formats

The application reads PDF files from your local storage for display purposes only. No data is uploaded, transmitted, or stored externally. Rendering is performed locally using the PDFium library.

7. Children's Privacy

Plain PDF Viewer does not collect any information from any users, regardless of age. The application is safe for use by all ages.

8. Your Rights and Choices

  • QuickJump list: Individual entries can be deleted from within the application at any time.
  • Reset Preferences: All settings can be removed by manually deleting the registry entries or uninstalling the app.
  • Full Removal: Uninstalling the application removes all associated registry entries.

We may update this Privacy Policy from time to time. Changes will be posted on this page with an updated "Last Updated" date.
