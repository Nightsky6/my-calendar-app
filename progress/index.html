수업진도 도우미

교사를 위한 수업 진도 기록 및 관리 앱.
간편하게 기록하고, 웹에서도 확인하세요.

⬇ 다운로드 (Windows)

주요 기능

수업진도 도우미는 교실 컴퓨터에서 바로 사용할 수 있는 무료 Windows 앱입니다. 별도의 회원가입 없이 설치 즉시 사용 가능합니다.
📝

과목별 진도 기록

과목을 등록하고 날짜, 쪽수, 내용을 간편하게 기록합니다. 지난 날짜로도 소급 입력이 가능합니다.

📅

학년도·학기 관리

학년도와 학기별로 데이터를 분리 관리합니다. 연도가 바뀌어도 이전 기록이 보존됩니다.

🌐

웹 동기화

동기화 버튼 한 번으로 교무실 PC나 스마트폰 브라우저에서 수업 진도를 조회할 수 있습니다.

🔒

비밀번호 보호

과목별 비밀번호를 설정하면 웹에서 해당 비밀번호를 입력해야만 진도를 열람할 수 있습니다.

🌙

다크 모드 지원

라이트·다크 모드를 지원하며, 아크릴·마이카 배경 효과로 쾌적한 사용 환경을 제공합니다.

🏫

학교 검색 연동

교육부 NEIS API를 통해 학교를 검색하고 등록할 수 있습니다.

📡 웹에서도 확인하세요

앱에서 동기화한 수업 진도를 웹 브라우저에서 언제 어디서나 조회할 수 있습니다. 과목별 비밀번호로 안전하게 보호됩니다.
