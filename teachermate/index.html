Teacher Mate

Windows Desktop Classroom Management App with Google Calendar & Google Tasks Integration

Application Purpose

Teacher Mate is a native Windows desktop application designed to help teachers efficiently manage their classrooms. It provides tools for student management, timetable planning, progress tracking, counseling records, seating arrangements, and more — all in one place. Teacher Mate also integrates with Google Calendar and Google Tasks so teachers can manage their schedules and to-do items without switching between apps.

Why Teacher Mate?

  • All-in-One Tool: Manage students, timetables, schedules, notes, photos, and tasks from a single app
  • Google Integration: Sync your schedule and tasks with Google Calendar and Google Tasks
  • Privacy-First: All classroom data is stored locally on your device
  • Cloud Backup: Securely back up and restore your data via Microsoft OneDrive
  • Modern Windows UI: Optimized for Windows 11 with a clean, intuitive interface

Key Features

  • Student Management: Maintain a student roster with photos and group assignments
  • Timetable: Create and manage weekly class timetables with a default fallback schedule
  • Seat Arrangement: Design and save classroom seating charts
  • Progress Tracking: Record lesson progress by class and subject, including page numbers and content
  • Counseling Records: Log and review individual student counseling notes
  • Photo Album: Organize and display class photos with a customizable layout canvas
  • My Notes: Write and manage personal teaching notes with category filtering
  • Attendance & Cleaning: Track attendance memos and cleaning duty assignments
  • Google Calendar Sync: View, create, edit, and delete calendar events synced with Google Calendar
  • Google Tasks Sync: Create, complete, and delete tasks synced with Google Tasks
  • OneDrive Backup & Restore: Back up and restore data per page (students, timetable, photos, notes) via Microsoft OneDrive

How It Works with Google Calendar & Google Tasks

Teacher Mate integrates with the Google Calendar API and Google Tasks API to provide the following functionality:

Google API Scopes Used:

  • email: Retrieve the user's email address for account identification
  • profile: Retrieve basic profile information (name, profile picture) for display within the app
  • calendar.readonly: View and display existing calendar events and schedules within the app
  • calendar: Create, modify, and delete calendar events synced with Google Calendar
  • tasks: Create, modify, complete, and delete tasks synced with Google Tasks
Data Usage: Teacher Mate only accesses the Google Calendar and Google Tasks data you explicitly authorize. All data is processed and stored locally on your device. We do not share your data with third parties, use it for advertising, or for any purpose other than displaying and managing your schedule and tasks within the app.

Privacy & Security

  • All classroom data (students, timetables, notes, etc.) is stored only on your local device
  • Google Calendar and Tasks data is accessed solely to display and manage your schedule within the app
  • No data is shared with third parties or stored on external servers by Teacher Mate
  • OneDrive backup is performed using your own Microsoft account under your full control
  • You can disconnect your Google account at any time from within the app
  • No advertisements, analytics, or usage tracking

System Requirements

  • Windows 11 or later
  • .NET 8.0 Runtime
  • Internet connection (required for Google Sign-In, Google Calendar/Tasks sync, and OneDrive backup)
