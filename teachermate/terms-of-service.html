2. Service Description

Teacher Mate is a Windows desktop application designed to help teachers manage their classrooms, integrated with Google Calendar and Google Tasks. The Application allows you to:

  • Manage student rosters, photos, and group assignments
  • Create and manage weekly timetables and lesson progress records
  • Design classroom seating arrangements
  • Record counseling notes and personal teaching memos
  • Organize class photo albums
  • Track attendance and cleaning duty assignments
  • View, create, edit, and delete Google Calendar events
  • Create, complete, and delete tasks synced with Google Tasks
  • Back up and restore classroom data via Microsoft OneDrive
